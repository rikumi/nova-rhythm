# Nova Rhythm runtime assets

Versioned static artwork and Apple SHARP Gaussian scenes for https://xtxl.rkm.mx/.

The website uses Raw URLs referencing the site-assets branch. Model filenames include their content hash. These large files are excluded from its GitHub Pages artifact. Model gzip files decompress losslessly to their original float32 PLYs; all predicted Gaussians are retained. This branch does not contain model weights.
