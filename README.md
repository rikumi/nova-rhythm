# Nova Rhythm runtime assets

Versioned static artwork and Apple SHARP Gaussian scenes for https://xtxl.rkm.mx/.

The website pins Raw URLs to immutable commits. These large files are excluded from its GitHub Pages artifact. Model gzip files decompress losslessly to their original float32 PLYs; all predicted Gaussians are retained. This branch does not contain model weights.
